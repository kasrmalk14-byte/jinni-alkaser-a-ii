# جني الكاسر AI — مشروع البداية الجاهز للبناء

هذا مشروع Flutter للمحادثة مع خادم خارجي متوافق مع OpenAI API. الواجهة ذهبية ملكية مع أزرق كهربائي.

## مهم قبل التشغيل
- هذا **مشروع مصدر قابل للبناء** وليس APK جاهزاً. يلزم بناء APK عبر Flutter بعد ضبط رابط الخادم.
- لا تضع مفتاح مزود الذكاء الاصطناعي داخل تطبيق الهاتف. المفتاح يبقى في الخادم فقط.
- مزود API قد يفرض رسوماً أو حدود استخدام. تحقق من الأسعار والرصيد قبل الاستخدام.
- سجل المحادثة محفوظ محلياً على الهاتف؛ لا يوجد حالياً حسابات مستخدمين أو دردشة هاتف-إلى-هاتف.

## 1) إعداد خادم الذكاء الاصطناعي
1. أنشئ حساباً لدى OpenRouter: https://openrouter.ai/
2. أنشئ API key من لوحة الحساب. لا ترسله لأي شخص.
3. انشر مجلد `backend` على استضافة Node.js أو Docker تدعم HTTPS.
4. انسخ متغيرات `backend/.env.example` إلى إعدادات Environment Variables في الاستضافة:
   - `AI_BASE_URL=https://openrouter.ai/api/v1`
   - `AI_API_KEY` = مفتاحك السري
   - `AI_MODEL` = اسم نموذج متاح في حسابك، مثال `openai/gpt-4o-mini`
5. بعد النشر افتح `https://رابط-خادمك/health` ويجب أن يظهر `{"ok":true,...}`.

يمكنك الاختبار محلياً:
```bash
cd backend
npm install
cp .env.example .env
# افتح .env وضع مفتاح API
npm start
```

## 2) بناء تطبيق Android APK
تحتاج جهاز كمبيوتر أو بيئة بناء فيها Flutter وAndroid SDK:
```bash
flutter pub get
flutter create --platforms=android .
flutter build apk --release --dart-define=BACKEND_URL=https://رابط-خادمك
```
الملف الناتج:
`build/app/outputs/flutter-apk/app-release.apk`

لا تستخدم `http://` في رابط الخادم المنشور؛ استخدم HTTPS.

## 3) البناء المجاني عبر GitHub Actions
1. ارفع محتويات هذا المشروع إلى مستودع GitHub.
2. افتح Settings > Secrets and variables > Actions.
3. أضف Secret باسم `BACKEND_URL` وقيمته رابط HTTPS لخادمك.
4. شغّل workflow المسمى `Build Android APK` من تبويب Actions.
5. نزّل `jinni-alkaser-apk` من Artifacts بعد نجاح البناء.

## 4) تخصيص النموذج
يمكن تغيير `AI_MODEL` في إعدادات الخادم إلى أي model ID متاح لدى مزودك. لا تفترض أن كل النماذج مجانية أو متاحة في بلدك.

## 5) حدود النسخة الحالية
- المحادثة مع الذكاء الاصطناعي تعمل عبر الخادم بعد نشره ووضع مفتاح صحيح.
- الردود غير متدفقة (تظهر بعد اكتمال الرد).
- لا توجد دردشة بين مستخدمين أو إشعارات فورية أو تسجيل دخول في هذه النسخة.
- لا يمكن ضمان أن النموذج أقوى من جميع المساعدات الأخرى؛ الجودة تعتمد على النموذج والاشتراك/الرصيد.
